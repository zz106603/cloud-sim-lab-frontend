# CloudSimLab Frontend Rules

1. 이 프로젝트는 Cloud/AWS 아키텍처 학습 시뮬레이션 프론트엔드다.
2. 프론트엔드는 단순 화면 표시보다 학습 흐름을 우선한다.
3. 사용자는 아래 흐름을 자연스럽게 이동할 수 있어야 한다.
   - 문서 목록
   - 문서 상세
   - 관련 시나리오
   - 시나리오 실행
   - 결과 확인
   - 복습 문서
4. 시나리오 선택 화면은 정답 맞히기보다 아키텍처 판단 연습에 초점을 둔다.
5. 결과 화면은 GOOD/PARTIAL/BAD만 보여주지 말고 판단 이유와 복습 연결을 함께 보여줄 수 있어야 한다.
6. 아키텍처 시각화는 사용자가 구조를 이해하는 데 도움이 되어야 한다.
   - 리소스
   - 네트워크 영역
   - 연결 관계
   - 선택 전/후 차이
7. 시각적 화려함보다 학습 이해도를 우선한다.
8. 기존 API 응답 계약을 임의로 변경하지 않는다.
9. 상태 관리, 라우팅, API 호출 구조 변경 시 기존 학습 흐름이 깨지지 않는지 확인한다.
10. UI 문구는 짧고 명확하게 작성한다.
11. 학습 콘텐츠 문구는 과장하지 않고 실제 클라우드 구조와 맞게 작성한다.
12. 컴포넌트는 화면 역할 기준으로 분리하고, 불필요하게 과도한 추상화는 하지 않는다.
